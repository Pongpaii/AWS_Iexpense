จุดเด่นด้าน Security / Cost

Security

  • S3 ปิด public ทั้งหมด เข้าถึงผ่าน CloudFront OAC เท่านั้น, บังคับ SSL
  • CSP เข้มงวด, HSTS preload, X-Frame-Options DENY, Permissions-Policy
  • ทุก route ของ API ต้องมี JWT จาก Cognito (default authorizer)
  • CORS จำกัดเฉพาะโดเมน CloudFront + localhost (dev / Capacitor)
  • GitHub OIDC จำกัด repo + branch main, session ≤ 1 ชม.
  • CI แก้สิทธิ์ของตัวเองไม่ได้ (CiStack deploy ด้วยมือ)

Cost guard (infra/lib/cost-guard.ts)

CDK Aspect ตรวจทุก resource ตอน synth — ผิดกฎ synth ล้มทันที
  • ห้าม RDS, EC2, NAT Gateway, EIP, ELB, ElastiCache, OpenSearch, WAF, KMS Key, Secrets Manager, RUM
  • Lambda: Node.js 22, arm64, 256 MB, timeout ≤ 10s, ไม่อยู่ใน VPC
  • Log group retention 7 วัน
  • DynamoDB ต้องเป็น PAY_PER_REQUEST

แจ้งเตือนค่าใช้จ่าย

  • Budget รายเดือน $20 แจ้งเมื่อ actual > $1, $5, $20
  • แจ้งเมื่อ forecast > $10
  • ไม่นับเครดิต/refund เพื่อไม่ให้เครดิตบังการใช้งานจริง
  • Cost Anomaly Detection รายวัน เมื่อผลกระทบ ≥ $1
